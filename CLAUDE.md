# AI Development Guidelines

## Project Overview

This is a full-stack capstone project developed as part of my software development internship.

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- Tailwind CSS
- JWT Authentication

## Development Conventions

- Use modern JavaScript (ES6+).
- Follow clear and consistent naming conventions.
- Build reusable React components.
- Keep frontend and backend responsibilities separated.
- Use RESTful API conventions.
- Keep sensitive information in environment variables.
- Write readable and maintainable code.
- Avoid unnecessary dependencies.
- Build responsive interfaces for mobile and desktop.
- Explain significant architectural decisions before implementing them.
- Prefer simple solutions over unnecessary complexity.



## Git Conventions

Use Conventional Commits.

Examples:

- `feat:` for new features
- `fix:` for bug fixes
- `docs:` for documentation
- `chore:` for configuration and setup
- `refactor:` for code restructuring
